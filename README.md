## 🌟 نظرة عامة على المنصة

**NUDHUJ AutoDeal OS** هي منصة SaaS متكاملة متعددة الشركات (**Multi-Tenant B2B Outbound Sales & Interactive Proposals Platform**) تدمج بين محرك وكلاء الذكاء الاصطناعي للمبيعات ومنظومة العروض الفنية والمالية التفاعلية تحت خادم واحد، لوحة تحكم واحدة، ودومين موحد.

### المميزات الجوهرية:
1. **الموقع التسويقي الاحترافي وبوابة الاشتراكات (`/`):**
   * شرح تفاعلي للمراحل السبعة للنظام، جدول مقارنة الباقات (`Starter Free`, `Growth Pro`, `Enterprise Scale`)، وتسجيل فوري ينشئ مساحة عمل مستقلة لكل شركة.
2. **محرك التعرف الذكي على أي شركة (`Company Profiler Agent`):**
   * يفحص موقع الشركة الإلكتروني أو ملف التعريف (Company Profile) ليولد تلقائياً ملف العميل المثالي (`ICP`) وعروض القيمة وكتالوج الخدمات والأسعار لأي نشاط تجاري.
3. **الوكلاء السبعة + الطيار الآلي (`Autopilot Scheduler`):**
   * استكشاف ديناميكي لأي قطاع (`Scout`) ⬅️ فحص البريد وتقييم الملاءمة (`Enricher`) ⬅️ صياغة سلاسل بريد مخصصة (`Writer`) ⬅️ سلم الموافقات والإرسال الذكي (`Sender`) ⬅️ قراءة الردود وإيقاف المتابعات تلقائياً (`Handler`) ⬅️ التحليلات (`Analyst`).
4. **منظومة العروض الفنية والمالية التفاعلية الموحدة (`/c/:slug`):**
   * تحويل مكالمات المبيعات والملاحظات إلى عروض تفاعلية محمية بـ 4 طبقات ملكية فكرية، مع ترقيات اختيارية تفاعلية، حاسبة عائد استثماري `ROI`، واعتماد إلكتروني فوري من العميل.
5. **مركز الإعدادات الشامل وفحص الجاهزية (`/app`):**
   * ضبط كامل لخوادم `SMTP/IMAP` ومفاتيح الذكاء الاصطناعي وسياسات الإرسال مع أزرار **فحص الاتصال الفوري** والحفظ الدائم.

## 🚀 التشغيل السريع (بنقرة زر واحدة)

### عبر ملف التشغيل المباشر (Windows):
انقر مرتين على ملف:
```cmd
start.bat
```

### أو عبر سطر الأوامر:
```powershell
# تشغيل المنصة الموحدة (الموقع التسويقي + لوحة التحكم + بوابة العروض)
python -m src.cli dashboard --port 8000

# تشغيل حزمة الاختبارات الآلية والتكاملية الشاملة (5 محاور SaaS)
python -m unittest discover -s tests -v
```

### الروابط الموحدة:
* **الموقع التسويقي وبوابة التسجيل والباقات:** `http://127.0.0.1:8000/`
* **لوحة التحكم الموحدة للمشتركين:** `http://127.0.0.1:8000/app`
* **استعراض العروض التفاعلية للعملاء:** `http://127.0.0.1:8000/c/{slug}`
* **حساب المدير العام الافتراضي (Super Admin):** `admin@nudhuj.com` / `Nudhuj@2026`
